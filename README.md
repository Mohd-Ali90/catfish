# Project-1 CatFish game


## Overview
CatFish is a luck-based game where you roll the dice to move cat, if you are able to find 3 fish you win. Otherwise, if you fall in a hole its game over. Your next roll will be higher if you land on a red tile and your next roll will be lower if you land on a blue tile.

Good luck.


## Technologies Used

1. HTML
2. CSS
3. Javascript

## User Stories 

1. As a user, I want to see the path that I can move along.
2. As a user, I want to roll a number and move based on that number.
3. As a user, if I land on a black square I expect that to indicate a game over (I fell in a hole).
4. As a user, if I land on a red square I expect that the next roll will move the player higher.
5. As a user, if I land on a blue square I expect that the next roll will move the player lower.
6. As a user ,if I land on a 'Fish' square I expect to gain +1 score (Fish counter).
7. As a user, I expect to win if I find 3 fish. 
8. As a user, I expect the 'Show/Hide rules' button to function accordingly.
