## User Stories 

1. As a user, I want to see the path that I can move along
2. As a user, I want to roll a number and move based on that number
3. As a user, if I land on a black square I expect that to indicate a game over (I fell in a hole)
4. As a user, if I land on a red square I expect that means I will move up based on the on the next number rolled
5. As a user, if I land on a blue square I expect that means I will move down based on the on the next number rolled
6. As a user, if I land on a white square i expect that means I will move left to right
7. As a user , if I land on a 'Fish' square I expect to gain +1 score (Fish counter)
